# AGRI SWNW - Smart Node 🌍
نظام إنترنت الأشياء (IoT) المتقدم لمراقبة وإدارة المزارع الذكية (Plug & Play).

## الميزات المعمارية (Core Features)
* **Dynamic Provisioning:** تخصيص ديناميكي لعدد وأنواع الحساسات والمنافذ (Pins) مباشرة من واجهة الويب.
* **Offline Redundancy:** 5 خطوط دفاع مدمجة تشمل رسائل الطوارئ SMS (SIM800L)، الراديو (LoRa/nRF24)، والتخزين المحلي (SPIFFS).
* **Web Flashing:** حرق السوفتوير وتهيئة الشريحة بالكامل من المتصفح باستخدام `ESP Web Tools` و `Web Serial API` دون الحاجة لأي برامج وسيطة.
* **Smart Telemetry:** مراقبة ذاتية لمستوى البطارية لضمان استمرارية التشغيل.

## طريقة التثبيت والتهيئة
1. قم بتوصيل شريحة **ESP32** بالكمبيوتر عبر كابل كابل بيانات (Data USB).
2. افتح لوحة تحكم التطبيق على **Oracle APEX**.
3. من شاشة `Device Setup`، حدد نوع وحدات الاتصال وعدد الحساسات.
4. اضغط على زر `Connect & Flash` ليقوم المتصفح بمسح الشريحة، حرق هذا السوفتوير، وإرسال حزمة الإعدادات (JSON Payload) برمشة عين.
